# cafe-landing

가상의 동네 카페 '모닝브루'를 소개하는 간단한 한 페이지짜리 랜딩 페이지입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 찾아오기, 푸터) |
| `style.css` | 디자인 스타일 (모바일 화면 대응 포함) |

## 사용 방법

별도 설치나 빌드 없이 `index.html`을 브라우저에서 열면 바로 확인할 수 있습니다.

## 참고

- 메뉴, 가격, 주소, 전화번호는 모두 예시 값입니다. 실제 카페 정보로 바꿔서 사용하십시오.
- 순수 HTML과 CSS로만 만들어 외부 라이브러리에 의존하지 않습니다.
